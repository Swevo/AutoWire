# AutoWire.Templates

`dotnet new` templates for [AutoWire](https://github.com/Swevo/AutoWire), the compile-time, Native AOT-safe DI registration source generator.

```bash
dotnet new install AutoWire.Templates
dotnet new autowire-webapi -n MyApp
```

| Template | Short name |
|---|---|
| Minimal API with AutoWire | `autowire-webapi` |
